# ss-extracts

Pre-built street-network extracts for SpaceSyntaxApp: 0.05-degree cells of
OSM highway data (Metro Manila coverage), rebuilt weekly by GitHub Actions
and published under the `extracts` release. Experimental Overture-sourced
cells under `extracts-overture`.

Data: (c) OpenStreetMap contributors, ODbL 1.0. Overture cells additionally
(c) Overture Maps Foundation.
